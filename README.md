## ☁️ Foco Principal: Azure Cosmos DB

Este projeto, em particular, foi desenvolvido enquanto eu aprendia a utilizar o **Azure Cosmos DB** em uma vídeo aula.

**O que é o Azure Cosmos DB?**
* É o serviço de banco de dados NoSQL totalmente gerenciado, distribuído globalmente e com múltiplas APIs da Microsoft Azure.
* Ele oferece latência de milissegundos de dígito único em qualquer escala, garantia de disponibilidade e suporta modelos de dados como **Documentos (SQL/Core API, MongoDB), Grafos (Gremlin), Colunas (Cassandra) e Chave-Valor (Table)**.
* É ideal para aplicações modernas que exigem alta performance, escalabilidade e distribuição geográfica.
